# AI-Interview-Assistant-Preparation-Platform-Project
Developed a responsive AI Interview Assistant web application with 4+ core modules including Login, Question Bank,
Mock Interview, and Feedback.
– Implemented 3 interview difficulty levels (Easy, Medium, Hard) containing technical interview questions across core
CS subjects.
– Integrated browser WebRTC and MediaRecorder APIs to enable 100 % client-side webcam streaming and interview
recording.
– Developed an interview recording feature allowing users to save and review their practice sessions locally.
